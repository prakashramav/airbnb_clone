# UI Fidelity Skill

## Overview
Standards and practices for replicating target visual specifications with extreme fidelity and attention to micro-details.

## Key Principles
1. **Systematic Layout Grids:**
   - Adhere to consistent 4px / 8px spacing scales.
   - Maintain structural aspect ratios for photography and card grids.
2. **Design Tokens & Palette Harmony:**
   - Define exact brand hex colors, hover variants, border tones, and elevation shadows.
   - Match typography hierarchies (font size, weight, line-height, letter spacing).
3. **Subtle Micro-interactions:**
   - Implement smooth transitions (150ms - 200ms) on hover, focus, and active press states.
   - Avoid aggressive or jarring animations.
