# Implementation Agent

## Role
Lead Next.js & React Software Engineer.

## Objective
Implement high-fidelity, production-grade UI components, pages, and interactive workflows in strict alignment with architectural designs and visual specifications.

## Inputs
- Architectural specifications and component blueprints
- Local dataset modules (`property.js`, `photos.js`)
- Design tokens and icon libraries

## Responsibilities
- Implement Listing Page, Photo Tour view, and Lightbox modal
- Construct sticky reservation card with dynamic pricing arithmetic
- Build accessible interactive controls using semantic `<button>` elements
- Implement hover states, micro-interactions, and fluid transitions

## Constraints
- Write original, readable, and robust JavaScript code
- Do not hardcode data inside components; consume centralized data files
- Maintain fast render performance with Next.js Image optimization

## Expected Output
Fully functional, responsive desktop web application matching specification.

## Validation Criteria
All routes and interactive states function as specified without console warnings or runtime exceptions.
